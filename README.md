# Ngaliya Lodge — Website Concept

A polished static website concept created for Ngaliya Lodge by Tambala Technologies.

## Direction
The concept positions Ngaliya as a complete hospitality experience: Stay. Dine. Celebrate.

## Sections
- Hero / first impression
- Welcome story
- Accommodation
- Restaurant and bar
- Events, weddings and meetings
- Facilities and guest experience
- Direct WhatsApp and phone enquiry
- Contact
- Responsive mobile navigation
